# Field runs

Copied engine JSON/MD. Not a wave, not a catalog member, not a `records/sweeps/`
row.

`tools/post_hanging_records.py` copies `checkwash/benchmarks/external/<date>/`
and sums MANIFEST totals from those files. Do not hand-edit the numbers.
Do not fold a field-run rate into a wave0 or wave1 headline.

Adjudication lives next to the copied sweeps so it cannot collide with
catalogued ids (rich is in both places, on different windows).
